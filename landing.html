The problem

Every session pays for the whole catalog.

Hermes builds an eager <available_skills> index into every system prompt — every skill name and description, paid as tokens on every API call. With 200+ skills that's 8–12k tokens of dead weight per session, whether or not a single skill gets used.

system prompt anatomy — one API call

system prompt available_skills user msg

≈8–12k tokens · paid on every call

base — instructions skills — 296 names + descriptions msg — the actual request

The index is the largest single line item in the prompt — and it's the one the agent almost never needs in full. It's paid for on every turn, in every session, for the lifetime of the conversation.

The fix isn't a bigger model or a cleverer prompt. It's not loading the catalog at all — and looking it up only when a skill is actually needed.

How it works

Discovery on demand, in one tool call.

A pre_llm_call hook injects a compact 240-char pointer into every session, so the agent knows to reach for skill_search — then the catalog stays out of context until it's needed.

Model choice

Tiny beats big when the texts are short.

Benchmarked on skill-retrieval tasks (5 easy + 4 hard queries). The winner is the smallest model that still discriminates — 45MB, runs on any old CPU, no GPU required.

embedding models, benchmarked on skill retrieval
Model Size Dims Easy Hard Verdict
all-minilm:l6-v2 45MB 384 5/5 3/4 ✓ chosen
granite-embedding:30m 62MB 384 5/5 3/4 tie, larger
snowflake-arctic-embed:22m 45MB 384 5/5 2/4 weak discrimination
nomic-embed-text 274MB 768 — — overkill for 200 short texts
bge-m3 1.2GB 1024 — — sledgehammer

Install

Up and running in five commands.

Prerequisites: Hermes Agent, Ollama running locally, Python 3.10+. The embedding model is a one-time 45MB pull.

  • ✓ ollama pull all-minilm:l6-v2 — 45MB, CPU-friendly
  • ✓ Copy the plugin into ~/.hermes/plugins/skill-search/
  • ✓ hermes plugins enable skill-search
  • ✓ Build the index: python scripts/skill_indexer.py
  • ✓ Restart: hermes gateway restart

Verify with hermes plugins list — the [Skill discovery] pointer appears in every session. Or test the index directly with python scripts/skill_search.py "plan a feature safely".

install.sh — 5 commands
$ ollama pull all-minilm:l6-v2 # 45MB, CPU-friendly $ git clone https://github.com/aldow3n-a11y/hermes-skill-search.git $ cp plugin/__init__.py plugin/plugin.yaml ~/.hermes/plugins/skill-search/ $ hermes plugins enable skill-search $ python scripts/skill_indexer.py # index native + OMH skills $ hermes gateway restart
